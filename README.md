# Smart-eTracking

Smart parking management for Guwahati Municipal Corporation: organizations, leased parking areas, slots, pricing, staff access, and operational records.

- [Admin panel setup and usage](backend/docs/admin-panel.md)
- [Staff login and role permissions](backend/docs/staff-access.md)
- [Database relationships and migration notes](backend/docs/database-design.md)

To explore the administration UI, run `npm install` and `npm run dev` in `frontend/`, open http://localhost:3000/dashboard/, and select **Explore demo**. For live data, follow the guide to prepare MySQL, configure the backend and provision a super administrator.
